# Multiplayer Game PoC

A real-time multiplayer card game Proof of Concept.

## Tech Stack & Versions

### Frontend
- **Framework**: React 19.x (via Vite)
- **Language**: TypeScript 5.x
- **Build Tool**: Vite 6.x
- **Real-time Library**: Socket.io-client 4.8.x
- **Styling**: Vanilla CSS (Modern CSS features like nesting and custom properties)

### Backend
- **Environment**: Node.js 22.13.1
- **Server**: Express 4.x
- **Real-time Library**: Socket.io 4.8.x
- **Development**: tsx (for direct TS execution)

## Execution
1.  **Server**: `cd server && npm install && npm start`
2.  **Client**: `cd client && npm install && npm run dev`
